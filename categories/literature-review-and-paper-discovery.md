# Literature Review & Paper Discovery

Tools and workflows for finding, retrieving, and assembling paper sets more efficiently.

- [openags/paper-search-mcp](https://github.com/openags/paper-search-mcp) — MCP server for searching and downloading academic papers across multiple sources. `Discovery` `MCP` `Search`
- [blazickjp/arxiv-mcp-server](https://github.com/blazickjp/arxiv-mcp-server) — MCP server for searching and retrieving arXiv papers in assistant workflows. `Discovery` `MCP` `arXiv`
- [wp-a/nature-academic-search](https://github.com/wp-a/nature-academic-search) — Codex and Claude Code skill with multi-source paper search, metadata verification, deduplication, and citation exports. `Discovery` `MCP` `Skills`
