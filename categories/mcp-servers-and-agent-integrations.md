# MCP Servers & Agent Integrations

Projects that connect academic sources, paper libraries, and workflows to AI assistants through MCP or similar interfaces.

- [54yyyu/zotero-mcp](https://github.com/54yyyu/zotero-mcp) — MCP server that connects Zotero libraries to AI assistants for summaries, citation analysis, annotations, and paper discussion. `MCP` `Zotero`
- [openags/paper-search-mcp](https://github.com/openags/paper-search-mcp) — Multi-source paper search MCP for academic workflows. `MCP` `Search`
- [blazickjp/arxiv-mcp-server](https://github.com/blazickjp/arxiv-mcp-server) — Agent-friendly arXiv search and retrieval through MCP. `MCP` `arXiv`
- [emi-dm/Research-MCP](https://github.com/emi-dm/Research-MCP) — MCP-first research workflow stack for academic use cases. `MCP` `Workflow`
- [smartbiblia-solutions/agent-skills](https://github.com/smartbiblia-solutions/agent-skills) — Includes agent-friendly integrations and scholarly workflow components. `MCP` `Integration`
