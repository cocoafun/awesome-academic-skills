# Reading, Summarization & Deep Research

Projects that help users read papers, extract useful information, and run deeper AI-assisted review workflows.

- [opendatalab/MinerU](https://github.com/opendatalab/MinerU) — Document parsing toolkit for converting complex PDFs into LLM-ready Markdown or JSON with support for formulas, tables, OCR, and reading-order reconstruction. `Reading` `Extraction` `PDF`
- [datalab-to/marker](https://github.com/datalab-to/marker) — PDF-to-Markdown and JSON converter tuned for fast, clean extraction from research papers and other structured documents. `Reading` `Extraction` `PDF`
- [Future-House/paper-qa](https://github.com/Future-House/paper-qa) — High-accuracy RAG system for answering questions from scientific literature with cited, evidence-grounded outputs. `Reading` `QA` `RAG`
- [LearningCircuit/local-deep-research](https://github.com/LearningCircuit/local-deep-research) — Local-first deep-research system for querying arXiv, PubMed, the web, and private documents with self-hosted and encrypted workflows. `Reading` `Deep Research` `Local`
- [binary-husky/gpt_academic](https://github.com/binary-husky/gpt_academic) — Academic AI toolbox for paper reading, translation, summarization, polishing, and project analysis across multiple LLM backends. `Reading` `Toolbox` `Writing`
- [Orchestra-Research/AI-research-SKILLs](https://github.com/Orchestra-Research/AI-research-SKILLs) — Large collection of research-oriented skills for literature survey, ideation, analysis, and paper workflows. `Reading` `Skills` `Research`
- [lingzhi227/agent-research-skills](https://github.com/lingzhi227/agent-research-skills) — Research skill pack for Claude Code covering literature search, reading, synthesis, and output generation. `Reading` `Skills` `Claude Code`
- [emi-dm/Research-MCP](https://github.com/emi-dm/Research-MCP) — Multi-step academic workflow stack for search, extraction, Q&A, and literature review. `Reading` `Workflow` `MCP`
