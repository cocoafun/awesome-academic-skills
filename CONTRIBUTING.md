# Contributing to Awesome Academic Skills

This repository is a curated list of links to open-source academic AI projects.

We prioritize tools that help researchers actually do work: paper discovery, reading, synthesis, scholarly integrations, and writing workflows.

## What Belongs Here

Add projects that are:

- open-source
- relevant to academic or research workflows
- useful in literature review, paper reading, synthesis, writing, or scholarly search
- meaningfully improved by agents, MCP, skills, or reusable workflow design

## What Usually Does Not Belong Here

- closed SaaS-only tools
- generic AI tool collections with no research focus
- traditional academic software with no workflow or agent angle
- thin wrappers, low-value demos, or abandoned repositories

## Entry Format

Add entries to the most relevant file under `categories/`:

```md
- [owner/repo](https://github.com/owner/repo) — Short factual description. `Tag1` `Tag2`
```

Guidelines:

- keep descriptions factual and concise
- prefer the repository root unless a subdirectory is the real project entry point
- use a small number of useful tags
- avoid hype language

## Where to Add

- put the project in the closest matching category file
- if a project clearly fits more than one workflow stage, it can appear in multiple categories
- if no category fits, open an issue before creating a new one

## Quality Bar

Before submitting, check that the project:

- has a clear README or documentation
- appears maintained enough to be useful
- has an identifiable academic or research use case
- is not obviously redundant with a much stronger entry already listed

## Pull Request Checklist

- link works
- category is appropriate
- description is accurate
- tags are consistent with nearby entries
- README navigation still matches category files if you added a new category

## Updates and Removals

Pull requests are also welcome for:

- fixing broken links
- tightening descriptions
- removing stale or clearly abandoned projects
- improving category structure
